# Basic-Notes-App-Android---Jetpack-Compose-
A basic notes app built with Kotlin, Jetpack Compose, and Room, featuring add, edit, and delete functionality with persistent local storage.

---

## Features

* Add notes
* Edit notes
* Delete notes
* Persistent storage using Room Database

---

## Tech Stack

* Kotlin
* Jetpack Compose
* Room Database
* ViewModel + Flow
